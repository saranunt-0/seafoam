# Seafoam node reference

Generated by `blender/tools/node_reference.py` from the node groups, so it matches the code.
Geometry groups are listed first, then shader groups. All geometry groups also work as modifiers.

## SF Gerstner Ocean

Open-sea waves as a sum of six Gerstner waves. Writes sf_foam_source where the surface is squeezed (Jacobian below the threshold), the stage 1 whitecap rule.

| Socket | Type | Default | What it does |
|---|---|---|---|
| Geometry | Geometry |  |  |
| Wavelength | Float | 24 | Longest wave in metres |
| Steepness | Float | 0.65 | Total crest sharpness. Above 1 the crests fold over |
| Direction | Float | 0° | Direction the waves travel |
| Spread | Float | 35° | How far wave directions fan out |
| Time Scale | Float | 1 | Speed the waves up or slow them down |
| Foam Below J | Float | 0.55 | Foam is born where the Jacobian drops below this |
| Foam Gain | Float | 4 | How quickly foam reaches full strength below the threshold |
| out: Geometry | Geometry |  |  |

## SF Shore Waves

Waves that shoal, curl and break on a plane beach, then run up the sand. The shoreline runs along X; the sea is toward -Y. Expects a dense grid.

| Socket | Type | Default | What it does |
|---|---|---|---|
| Geometry | Geometry |  |  |
| Shoreline Y | Float | 0 | Still-water shoreline, in object space |
| Beach Slope | Float | 0.0666667 | Rise per metre. Steeper beaches plunge, gentle ones spill |
| Wave Height | Float | 1.2 | Offshore wave height in metres |
| Wave Period | Float | 8 | Seconds between crests |
| Wave Angle | Float | 12° | Crest angle to the shoreline. Non-zero makes the break peel along the beach |
| Offshore Depth | Float | 8 | The sea floor flattens out at this depth |
| Breaking Index | Float | 0.78 | Waves break when height / depth reaches this (McCowan 0.78) |
| Curl | Float | 1 | How far the crest rotates over into a lip when the wave plunges |
| Lean | Float | 0.7 | Forward tilt of the crest as it breaks (Fournier & Reeves) |
| Run-up | Float | 1 | Scale on Hunt's run-up distance |
| Irregularity | Float | 0.35 | Wobbly crests and wave sets |
| Time Scale | Float | 1 | Speed the waves up or slow them down |
| Foam Gain | Float | 1 | Multiplies every foam source: whitewater, bores and swash |
| out: Geometry | Geometry |  |  |

## SF Foam Accumulate

Gives foam a life: each frame the old foam spreads, fades and drifts, and new foam from the source attribute is added. foam = max(spread(foam) * exp(-dt / life), source).

| Socket | Type | Default | What it does |
|---|---|---|---|
| Geometry | Geometry |  |  |
| Source Attribute | String | `sf_foam_source` | Float attribute where foam is born |
| Wet Attribute | String | `sf_wet` | 1 = water, 0 = dry sand. Missing means all wet |
| Lifetime Wet | Float | 5 | Seconds for foam on water to fade to 37% |
| Lifetime Dry | Float | 25 | Seconds for foam stranded on sand to fade |
| Spread | Integer | 1 | Blur steps per frame; foam disperses |
| Drift | Vector | (0, 0, 0) | Metres per second the foam is carried |
| out: Geometry | Geometry |  |  |

## SF Spray

Throws ballistic droplets from the sf_spray attribute (breaking lips) and adds them to the geometry as small spheres. Simulated, so play or bake from the start frame.

| Socket | Type | Default | What it does |
|---|---|---|---|
| Geometry | Geometry |  |  |
| Weight Attribute | String | `sf_spray` | Float attribute: where to throw droplets from |
| Rate | Float | 12 | Droplets per square metre per second at full weight |
| Up Speed | Float | 3.5 | Upward launch speed, m/s |
| Throw | Vector | (0, 3, 0) | Extra launch velocity, m/s (toward the beach) |
| Jitter | Float | 1.2 | Random spread of launch velocity, m/s |
| Lifetime | Float | 1.1 | Seconds a droplet lives |
| Size | Float | 0.09 | Droplet radius in metres |
| Material | Material |  | Material for the droplets, e.g. SF Spray |
| out: Geometry | Geometry |  |  |

## SF Beach

A sand beach matching SF Shore Waves: plane slope, flat sea floor, small ripples. Ignores its input geometry, so put it on any mesh object.

| Socket | Type | Default | What it does |
|---|---|---|---|
| Geometry | Geometry |  |  |
| Width | Float | 120 | Along the shoreline (X) |
| Land | Float | 30 | Dry beach behind the shoreline |
| Sea | Float | 150 | Sea floor in front of the shoreline |
| Spacing | Float | 0.5 | Grid spacing in metres |
| Shoreline Y | Float | 0 | Match SF Shore Waves |
| Beach Slope | Float | 0.0666667 | Match SF Shore Waves |
| Offshore Depth | Float | 8 | Match SF Shore Waves |

| Material | Material |  | Material for the sand, e.g. SF Sand |
